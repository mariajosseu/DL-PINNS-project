# DL-PINNS-project

A small ML/DL project starter, organized in the spirit of Cookiecutter Data Science.
This is a custom lightweight scaffold, not generated by the official Cookiecutter CLI.
No models, assignment solutions, training code or report text are included.

## Layout

- `src/dl_pinns/`: your reusable Python implementation
- `configs/`: experiment configurations
- `notebooks/`: exploration
- `tests/`: your tests
- `data/raw/`, `data/processed/`: local datasets, excluded from Git
- `outputs/checkpoints/`, `outputs/figures/`, `outputs/runs/`: generated results, excluded from Git
- `logs/`: job logs, excluded from Git
- `hpc/`: DTU environment and synchronization instructions

## Local setup (Mac)

With Python 3.11 or newer installed:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
```

Install PyTorch separately for your machine using the official installation selector:
https://pytorch.org/get-started/locally/
Mac and HPC require separate environments and potentially different PyTorch builds.

## GitHub and HPC

Edit locally, inspect `git status` and `git diff`, then commit and push selected files.
On HPC, update with `git pull --ff-only`. See [HPC instructions](hpc/README.md).
Do not commit passwords, environments, datasets or generated training artifacts.
Dependency ranges are not locked yet; record exact working versions separately for
Mac and HPC once the environments are verified.
